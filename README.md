# Planet Tablist

A simple accessible tab component built with HTML, CSS, and JavaScript.

## Features

- Switch between planet information using tabs
- Only one panel is displayed at a time
- Uses JavaScript event listeners to update content
- Implements ARIA attributes for accessibility
- Responsive and easy to use

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## What I Learned

Through this project, I practiced:

- Working with the DOM
- Using `querySelectorAll()`
- Looping through NodeLists with `forEach()`
- Adding click event listeners
- Managing ARIA attributes such as `aria-selected`
- Showing and hiding content dynamically
- Building accessible tab interfaces

## Project Preview

Users can click different planet tabs to view information about each planet. When a new tab is selected, the previous panel is hidden and the selected panel is displayed.
